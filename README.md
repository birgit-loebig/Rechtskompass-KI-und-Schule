# Rechtskompass KI und Schule

Nachschlagewerk zu den Rechtsgrundlagen für den Einsatz von KI an hessischen Schulen (Schulamtsbezirk Bergstraße/Odenwald), mit Fundstelle, Originalwortlaut, Stand und Quellenlink.

Erstellt von Birgit Löbig (Starkenburg-Gymnasium Heppenheim), Mitglied der AG „KI und Schule“ am Staatlichen Schulamt Bergstraße/Odenwaldkreis.

Die Seite besteht aus `index.html` und dem Ordner `dokumente/`. Sie wird über Netlify veröffentlicht. Keine Rechtsberatung; siehe „Haftungsausschluss & Rechtliche Hinweise“ auf der Seite.
